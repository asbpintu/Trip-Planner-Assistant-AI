## Trip Planner Assistant AI

##### An AI-powered intelligent travel planning assistant that creates personalized itineraries, travel recommendations, budget analysis, and complete trip plans through a multi-agent AI workflow.



### Project Goal

Develop an AI-powered travel planning application that helps users create personalized travel itineraries using natural language.



### The application generates:

Trip overview
Day-wise itinerary
Estimated budget
Weather
Currency information
Packing checklist
Recommended places
